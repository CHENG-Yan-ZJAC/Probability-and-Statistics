\chapter{参数估计}

本章讨论参数估计及其评价方法。
参数估计是数理统计的一个基本问题，讨论的是如何使用样本估计总体的未知信息。

参数估计有点估计和区间估计：
\begin{itemize}
    \item 点估计：用样本估计总体的分布的未知参数，有矩估计法、极大似然估计法、贝叶斯估计法等；
    \item 区间估计：估计未知参数的取值范围。
\end{itemize}

本章要点：
\begin{itemize}
    \item 矩估计法。
    \item 极大似然估计法。
    \item 估计量的评价标准。
    \item 区间估计。
\end{itemize}
