\chapter{一维随机变量及其分布}

本章从具体的试验中抽象出来，用函数工具讨论概率的分布规律。

本章要点：
\begin{itemize}
    \item 一维随机变量的概念，以及2个大类，离散型和连续型。
    \item 一维离散型随机变量的分布律，及5大常见的分布律。
    \item 一维连续型随机变量的密度函数，及3大常见的密度函数。
    \item 一维随机变量的函数。
\end{itemize}
